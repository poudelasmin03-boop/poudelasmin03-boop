## Detailed Project Breakdown

### 1. PayFlow — Digital Payment System
- **Overview:** Developed a full-featured digital payment platform designed to handle QR-based transactions, merchant onboarding, and financial record keeping.
- **Key Features:**
  - Integrated a computer vision-based KYC verification workflow using facial recognition to cross-reference user profile photos with identity documents.
  - Implemented automated validation rules and document number extraction to simplify user and merchant registration pipelines.
  - Built secure ledger and transaction tracking mechanics backed by PostgreSQL.
- **Tech Stack:** Django · OpenCV · PostgreSQL

### 2. Smart Tourism Bike Rental System
- **Overview:** Engineered a tourism-focused bike rental web application tailored for searching, booking, and managing vehicle rentals seamlessly.
- **Key Features:**
  - Developed comprehensive administrative tools for monitoring vehicle availability, managing fleet inventory, and approving bookings.
  - Implemented automated recommendation logic based on tourist requirements to help users explore and select ideal travel options.
- **Tech Stack:** Django · PostgreSQL

### 3. Face Recognition Attendance System
- **Overview:** Created a real-time student attendance tracking application to eliminate manual paperwork and speed up classroom processing.
- **Key Features:**
  - Built webcam-based video stream processing using OpenCV to detect and recognize registered student faces dynamically.
  - Automated attendance logging directly into the database with precise timestamps and status flags.
- **Tech Stack:** Django · OpenCV · Python

### 4. Marriage Registration System
- **Overview:** Designed and built a digital governance application for managing and preserving official marriage registration records.
- **Key Features:**
  - Implemented strict document validation workflows and structured dynamic forms for collecting and verifying applicant credentials.
  - Utilized PostgreSQL with Django ORM for robust data integrity and structured reporting.
- **Tech Stack:** Django · PostgreSQL · JavaScript · HTML · CSS
